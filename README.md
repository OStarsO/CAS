# 课堂抽卡点名系统 · CAS

一个单文件、离线可用的课堂随机点名 / 抽卡系统。液态玻璃视觉，星空与阳光双主题，六种以上抽取动画，带概率、保底、成就、统计与导出。

> **非商业使用（Non-commercial）**：本项目仅供课堂教学与个人学习交流使用，不得用于任何商业用途。

## 直接使用

下载 `index.html`，双击即可在浏览器打开，**无需联网、无需安装、无需服务器**。

所有数据（名单、历史、设置、概率、保底进度、成就）都保存在浏览器的 `localStorage` 中，换浏览器或清理浏览器数据会丢失，请用「设置 → 导出备份 JSON」定期备份。

## 功能

**点名与抽取**
- 不重复 / 可重复两种模式，切换需二次确认，可保留或重置「已抽」标记
- 单抽、批量抽取（1–50 人）、可重复模式下按分组等比例抽取
- 十连逐张揭示：点击卡牌翻下一张，全部展示后自动平铺验收，支持「跳过」、`←`/`→`/空格/回车
- 抽取范围可在「全部分组 / 当前分组」间切换，名单与抽取池同步过滤

**概率与保底**
- 1–5★ 概率自定义，合计必须为 100%，另提供标准 / 欧皇 / 非酋 / 全员五星预设
- 权重模式：按 1–5 倍权重换算百分比，带均衡 / 稀有 / 宽松预设与概率模拟
- 保底（默认关闭）：十连至少 1 个 4★、50 抽必出 5★；舞台显示进度条与触发提示
- 幸运值：连续未出五星时逐步提升五星权重（可配步长与上限）

**名单**
- 姓名 / 学号 / 分组三字段；行内编辑支持 `Enter` 保存、`Esc` 取消、`Tab` 切换字段
- 搜索、全部/未抽/已抽筛选、升/降序，排序支持添加顺序 / 姓名 / 学号 / 拼音首字母 / 抽中次数 / 抽中状态
- 分组颜色、改名、解散；临时排除某人（灰显且持久化）；单个/批量放回候选池
- 长按多选（阈值可调）、右键菜单、200 人以上自动虚拟滚动

**导入导出**
- 导入：粘贴文本、CSV、TXT、JSON、**Excel（.xlsx/.xls/.xlsm，内置 SheetJS，完全离线）**
- 导入实时预览有效条数、空行、重复学号、重名提示；可追加 / 替换 / 按学号更新；多工作表可选
- 导出：CSV、TXT、JSON 备份、PNG 卡片、分享长图、十连结果长图、Excel（三工作表）、打印（全部/名单/历史）

**其他**
- 音效 17 种 + 3 首可关闭 BGM，音效/总音量/音乐三通道独立调节
- 26 项成就分 6 类，解锁弹窗与光效；7 档称号可佩戴并显示在舞台与分享图
- 统计面板：总抽取、去重人数、五星率、覆盖率、星级分布图、排行榜、操作日志
- 撤销 / 重做 50 步，最近 10 步跨刷新保留
- 固定种子可复现同一批结果（历史记录带哈希）
- 中英切换、8 种动画、4 套卡面皮肤、深/浅双主题、打印样式、PWA manifest
- 全局快捷键可自定义、冲突提示、总开关（空格/回车单抽、Shift+空格十连、E/H/I/S/P/R 等）

## 兼容性

Chrome / Edge / Firefox / Safari 现代版本；移动端可用（Dock 横向滚动、十连两列、键盘弹出自动收起）。`file://` 直接打开与静态托管均可。

## 目录

```
index.html     页面结构与文案（47 KB）
styles.css     全部样式（109 KB）
app.js         全部业务逻辑（297 KB）
xlsx.b64.js    base64 内联 SheetJS（1.17 MB，导入/导出 Excel 时才解码加载）
README.md
LICENSE
```

四个文件需保持在同一目录；`index.html` 用相对路径引用另外三个，所以本地 `file://` 直接打开和静态托管都能跑。
